Help / notes
First run generates the ~590 MB support tables in wasm and may take a few minutes; only the first run is slow. Running twophase additionally generates ~126 MB of pruning tables the first time (pt_drud_sym16_HTM + pt_drudfin_noE_sym16_drud). The light step is a true optimal solve using ~114 MB of tables (pt_drud_sym16_HTM + pt_corners_HTM) and is slow single-threaded; the fast optimal step needs a ~2.3 GB table and is not available in the browser. Everything is cached afterwards; the progress bar shows generation/search activity (pruning-table generation is the only phase with an exact percentage).
